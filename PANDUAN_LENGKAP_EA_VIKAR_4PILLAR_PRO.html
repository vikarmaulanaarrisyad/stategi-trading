🏛️ BAB 1: ARSITEKTUR INTI 4 PILAR KONFLUENSI

Robot trading VIKAR 4-Pillar Pro dirancang dengan prinsip dasar trader institusional dunia: "Never trade on a single indicator". Robot tidak pernah membuka order hanya karena satu sinyal lilin atau indikator biasa, melainkan mengharuskan terjadinya konfluensi serempak (pembobotan skor minimal 65-75 poin) dari 4 pilar analisa berikut:

1. SMC Struktur & Likuiditas Pilar 1

Mengidentifikasi Break of Structure (BOS), Change of Character (CHoCH), Order Block institusional (Demand & Supply Base), serta Fair Value Gap (FVG Imbalance). Robot juga memfilter harga berdasarkan Dealing Range: hanya BUY di zona Discount (murah) dan hanya SELL di zona Premium (mahal).

2. Triple Ribbon EMA Pilar 2

Memanfaatkan 3 lapis Exponential Moving Average berkecepatan tinggi: EMA 8 Aqua (Trigger Entry), EMA 21 Magenta (Dinamika Pullback), dan EMA 125 Gold (Filter Arah Makro Tren). Posisi BUY hanya diizinkan jika harga berada di atas EMA 125.

3. Golden Pocket Fibonacci Pilar 3

Menarik garis Fibonacci secara otomatis dari ayunan Swing Low ke Swing High terakhir. Robot mencari area pantulan optimal (*Optimal Trade Entry* - OTE) pada zona 50.0% s/d 61.8% Golden Pocket untuk menghasilkan Risk-to-Reward terbaik.

4. Daily Pivot Point S/R Pilar 4

Kalkulasi otomatis garis Pivot harian, R1, R2, S1, dan S2 dari harga penutupan hari kemarin. Digunakan sebagai Double Alignment untuk memvalidasi bahwa harga tidak sedang membentur tembok resisten/support horizontal besar.

Sistem Penilaian Skor Konfluensi (0 - 100 Poin):
Tiap setup yang terdeteksi dihitung skor kualitasnya secara otomatis: Struktur SMC (20 pt) + Rebound Order Block (20 pt) + FVG (15 pt) + Penembusan BOS (15 pt) + Fibonacci OTE (10 pt) + Ribbon EMA (10 pt) + Pola Lilin (10 pt) + Bonus VSA (+10 pt). Hanya setup dengan skor ≥ 65 poin (Grade A) atau ≥ 85 poin (Grade A+ Sniper) yang akan dieksekusi.

🧠 BAB 3: KECERDASAN BUATAN (AI) & KOREKSI DIRI MANDIRI

Salah satu keunggulan terbesar EA VIKAR dibanding robot konvensional adalah kemampuannya untuk belajar dari kesalahan dan menyesuaikan diri secara otomatis terhadap kondisi pasar:

1. Autonomous Neuro-Calibration & Self-Tuning (v3.20)

Secara otomatis membaca rasio volatilitas terkini (ATR 14 vs ATR 100) dan indeks pasar (Choppiness Index) untuk mengubah parameter secara mandiri:

  • Kondisi Normal: Menggunakan buffer SL standar 1.0x dan cooldown 2 bar.
  • Pasar Volatilitas Tinggi / Berita (Vol Ratio ≥ 1.25): Robot memperlebar jarak SL dan buffer trailing lilin sebesar 1.4x agar order tidak tersapu noise, serta menaikkan syarat skor entry (+10 pt).
  • Pasar Sideways Choppy (CI > 61.8): Robot memperketat buffer SL menjadi 0.9x untuk menghemat risiko modal dan menambah cooldown jeda order.
  • Anti-Tilt Mode Pasca 2x Loss Beruntun: Robot menaikkan syarat skor kualitas konfluensi (+5 hingga +15 pt) dan melipatgandakan cooldown lilin (4-8 bar) untuk mencegah revenge trading.

2. Mesin Otopsi 7 Skenario Pasca-SL (Self-Healing Engine v3.10)

Jika terjadi transaksi yang terkena Stop Loss riil, robot tidak langsung membuka posisi baru secara serampangan. Robot mengaktifkan algoritma otopsi untuk mendiagnosa 1 dari 7 penyebab kegagalan:

[DIAGNOSA OTOPSI] 1. VOLATILITAS ABNORMAL (NEWS SHOCK) → Rentang lilin > 2x ATR 2. JEBAKAN SIDEWAYS NOISE → Choppiness Index > 61.8 3. PEMBALIKAN STRUKTUR MAKRO → Lilin menembus batas EMA 125 4. JAM RAWAN LOSS (TOXIC HOUR) → Terjadi 2x loss pada jam server yang sama 5. DIRECTIONAL ERROR (MELAWAN TREN) → Posisi melawan arah ribbon makro 6. PENGUJIAN LEVEL GAGAL → Penolakan level S/R tidak valid 7. SPREAD ANOMALY SPIKE → Pelebaran spread sesaat di luar batas wajar

Tindakan Koreksi Diri Otomatis: Robot memberikan penalti skor (+10 poin), mengarantina pola lilin yang gagal selama 15 bar, memblokir arah transaksi yang sama selama 12 bar, dan memberikan ekstra buffer SL pada 3 transaksi berikutnya.

3. Dynamic Pattern Performance Matrix

Robot menyimpan buku rapor performa untuk ke-13 pola lilin. Jika suatu pola memiliki Win Rate < 40% (minimal 3x transaksi), pola tersebut akan di-blacklist sementara. Sebaliknya, jika Win Rate ≥ 70%, pola tersebut mendapat Boost (+10 poin).

🛡️ BAB 4: PROTEKSI MODAL & PROP FIRM EQUITY GUARDIAN

Prop Firm Equity Guardian Anti-Bust

Mengunci equity harian secara ketat. Jika penurunan modal harian (Drawdown) menyentuh batas maksimal (default 4.0%), robot langsung menutup seluruh order aktif dan mengunci trading hingga esok hari. Menjamin akun tantangan Prop Firm (FTMO, FundedNext, dll) tidak akan pernah terkena pelanggaran batas harian.

Circuit Breaker 2x Loss Cooldown Anti-Overtrade

Jika robot mengalami 2 kali kerugian berturut-turut, sistem Circuit Breaker otomatis menghentikan aktivitas trading selama 4 jam penuh. Memberikan waktu bagi pasar untuk meredakan gejolak sebelum robot mulai mencari setup baru.

Friday Weekend Guard Anti-Gap

Setiap hari Jumat pukul 21:00 server time, robot otomatis melikuidasi seluruh posisi mengambang dan membekukan order baru. Menghindarkan akun Anda dari risiko lonjakan harga (*gap open*) yang tidak terduga pada pembukaan hari Senin pagi.

Pre-News & Spread Spike Shield News Filter

Membekukan entry baru 15 menit sebelum hingga 15 menit sesudah rilis berita besar (NFP, CPI, FOMC, Fed Rate). Serta membekukan transaksi secara seketika jika spread emas melebar abnormal di atas batas toleransi broker.

📈 BAB 6: 5 SISTEM TRAILING STOP BERLAPIS & MANAJEMEN POSISI

EA VIKAR dilengkapi sistem pengawalan profit bertingkat (*multi-layer trailing*) yang bekerja secara simultan dengan aturan Ratchet (Satu Arah): Stop Loss hanya akan bergeser jika harga baru lebih menguntungkan dibanding posisi saat ini dan tidak akan pernah mundur ke belakang.

1. Auto-Breakeven (SL+) Proteksi Awal

Begitu posisi berjalan floating profit +5 pips (50 point), SL langsung dipindahkan ke +2 pips (20 point) di atas harga open. Posisi otomatis bebas risiko (*risk-free trade*).

2. Dynamic Points Trailing Pengawal Harga

Aktif setelah profit mencapai 40 point. Menjaga jarak pengawalan 30 point di belakang harga, dan menggeser SL tiap harga bergerak maju sejauh 10 point.

3. Candle-by-Candle Trailing Ekor Lilin

Tiap candle baru terbentuk, SL dinaikkan tepat di bawah titik terendah candle sebelumnya (Low[1] untuk BUY) dengan buffer 15 point. Sangat efektif saat terjadi tren kuat (*runaway trend*).

4. Ribbon EMA 21 Trailing Kurva Dinamis

Stop Loss merayap naik mengikuti kurva dinamis EMA 21 Magenta. Memberikan ruang bernapas yang cukup bagi pasar untuk bernafas tanpa mengorbankan tren besar.

5. SMC Structural Swing Trailing (Khusus Runner Pasca TP1 50%) SMC Runner

Saat harga menyentuh TP1, robot melakukan Partial Close 50% lot untuk mengamankan uang ke saldo riil. Sisa 50% lot (*runner*) dikawal khusus menggunakan ayunan struktur Higher Low (HL) atau Lower High (LH) pasar institusional hingga tren benar-benar berakhir.

💻 BAB 7: PANDUAN PEMASANGAN DI METATRADER 4 & MT5

Langkah 1: Menyalin File Robot ke Folder Terminal

  1. Buka terminal MetaTrader 4 atau MetaTrader 5 Anda.
  2. Klik menu File → pilih Open Data Folder.
  3. Masuk ke folder:
    • MT4: MQL4 → Experts → Tempelkan file VIKAR_EA_4Pillar_SMC_EMA_Fibo_SR_MT4.ex4.
    • MT5: MQL5 → Experts → Tempelkan file VIKAR_EA_4Pillar_SMC_EMA_Fibo_SR.ex5.
  4. Kembali ke terminal, pada jendela Navigator, klik kanan folder Expert Advisors → klik Refresh.

Langkah 2: Menyiapkan Chart & Mengaktifkan AutoTrading

  1. Buka chart XAUUSD (Gold) pada timeframe M5 atau M15.
  2. Pastikan tombol AutoTrading (di MT4) atau Algo Trading (di MT5) pada toolbar atas sudah menyala HIJAU.
  3. Tarik robot dari Navigator ke dalam chart.
  4. Pada jendela pengaturan tab Common:
    • Centang Allow Live Trading / Allow Algo Trading.
    • Centang Allow DLL imports (jika diminta).
  5. Pada tab Inputs, seluruh parameter bawaan (*default*) sudah dioptimalkan untuk scalping emas. Klik OK.

Langkah 3: Membaca Dashboard HUD & Fitur Geser (Drag-and-Drop)

Dashboard modern berwarna gelap (*dark glassmorphic*) akan muncul di sisi kiri atas chart:

  • Di pojok kanan atas banner dashboard terdapat tombol [ :: GESER ] (MT4) atau [ ⠿ GESER ] (MT5).
  • Klik tombol tersebut → tombol akan berubah menjadi warna kuning [ LEPAS ].
  • Sekarang Anda dapat mengklik di mana saja di chart untuk memindahkan posisi dashboard agar tidak menutupi grafik lilin Anda. Klik sekali lagi untuk mengunci posisi.

2. Aturan Emas Menjalankan EA Vikar 4-Pillar Pro

  1. Gunakan VPS (Virtual Private Server) yang Stabil: Agar EA dapat mengawal trailing stop dan mengeksekusi Auto-Breakeven secara 24 jam nonstop tanpa terganggu pemadaman listrik atau koneksi internet rumah yang terputus.

  4. Biarkan Robot Mengelola Transaksi: Hindari kebiasaan menggeser Stop Loss secara manual ke arah yang merugikan. Robot telah dibekali 5 sistem trailing stop dan otopsi pasca-loss untuk melindungi modal Anda secara matematis.
